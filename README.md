# ns3-5g-lena-simulations-project
ns-3 + 5G-LENA simulations for 5G slicing and RL experiments.

## Supervisor-meeting deck

- `Meeting.pptx`: original presentation (never modified by the script).
- `edit_ppt.py`: builds the revised deck with python-pptx.
  Run `pip install -r requirements.txt && python3 edit_ppt.py`, which writes `Meeting_revised.pptx`.
- `Meeting_revised.pptx`: generated deck (31 main slides + 24 appendix slides, with speaker notes).
- `docs/research_review.md`: the analysis behind the deck. It contains the survey comparison, the paper and reviewer audit, the research directions, the datasets and infrastructure, the evaluation protocol, the action plan and the evidence ledger.
